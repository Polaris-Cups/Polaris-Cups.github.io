# CUPS — Polaris

A responsive English, Russian and Persian team portfolio. Open `index.html` or serve the folder as a static website. Tailwind 3.4.17 loads from its CDN, so an internet connection is required to render the layout. There is no local Tailwind copy or build step.

The Persian font is bundled locally. All images are WebP. The hero artwork is a transparent WebP derived from the supplied cup illustration, and the Two of Cups card is the supplied team image converted to WebP.

Eight projects are presented. Noghreluna, Noghrehana and Tahanoa Invoice Links use the three demo images supplied for this project; clicking their cards opens the original site or plugin page. The three other project photographs came from Unsplash (photo IDs `1551288049-bebda4e38f71`, `1498050108023-c5249f4df085`, `1460925895917-afdab827c52f`).
